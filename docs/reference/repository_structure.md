# Repository Structure

Highlights by top-level directory:

- `src/scperturb_cmap/` – Python package code (API, CLI, models, data loaders)
- `docs/` – MkDocs site content
- `examples/data/` – Demo assets used by the tutorials and tests
- `examples/case_studies/` – Reproducible workflows for published analyses
- `deployment/` – Docker, Helm, and cloud automation assets
- `tests/` – Unit and integration test suite

Use this page as a quick reminder while browsing the documentation.
