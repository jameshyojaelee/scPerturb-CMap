# Tutorials

These tutorials walk through common scPerturb-CMap workflows in a notebook-style format while remaining versioned through `mike`. Each page mirrors a runnable sequence of cells you can execute locally after a quick `make setup`.

- **CLI + Streamlit Walkthrough:** end-to-end tour that builds a target signature, scores against the demo LINCS library, then pivots into the Streamlit UI for interactive exploration.
- More tutorials will follow as new workflows land (e.g., custom LINCS libraries, metric-model training).

Tips:
- Use `make demo` to materialise the small synthetic LINCS assets referenced below.
- Switch versions with the version selector in the sidebar (powered by `mike deploy` on tagged releases).
